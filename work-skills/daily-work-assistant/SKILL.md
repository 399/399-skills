# 日常工作助理

## 目标

围绕日常办公资料完成“查找来源—读取核对—结构化整理—形成结论—输出成果”的闭环。优先使用飞书文档作为动态事实源，必要时补充读取用户上传的 Word、Excel、PDF、Markdown 或纯文本文件。

## 核心原则

1. **先结论后依据**：先给出用户最需要的结论，再提供依据、待办、风险和来源。
2. **事实可追溯**：保留文档标题、链接、日期、章节或其他定位信息。
3. **不补造事实**：资料未明确记录的内容标记为“待确认”“信息缺失”或“推测”，不得写成确定事实。
4. **冲突不擅自裁决**：多份资料冲突时并列展示冲突内容与各自来源，请用户确认。
5. **动态资料不重复沉淀**：不要默认把全部飞书资料复制成本地或项目资产，只沉淀用户确认的正式成果、稳定规则或复用模板。
6. **外部写操作先确认**：修改飞书文档、发送消息、创建或更新任务与日程、上传或覆盖共享文件前，先展示拟执行内容并取得明确确认。
7. **最小必要读取**：优先读取用户指定资料；未指定时，根据主题、时间和对象检索最相关文档，避免无目的地遍历全部资料。

## 任务识别

根据请求选择一个或多个工作流：

- **文档整理与总结**：适用于“整理这份文档”“提炼重点”“给我结论”“汇总几份资料”。
- **会议纪要与待办**：适用于“整理会议纪要”“提取行动项”“谁负责什么”“有哪些决策”。
- **周报与进展汇总**：适用于“写周报”“汇总本周进展”“生成项目进展报告”“整理下周计划”。
- **资料归类与检索**：适用于“找相关资料”“按主题归类”“建立索引”“追溯某个结论来自哪里”。

## 标准工作流

### 1. 明确任务边界

提取主题、对象、时间范围、资料范围、输出用途和期望格式。只有缺少的信息会显著影响结果时才提问；否则采用合理的最小假设，并在结果中说明。

### 2. 获取原始资料

- 用户指定飞书文档时，优先读取指定文档。
- 用户未指定资料但涉及办公事实时，按主题、项目、人员、会议名和时间范围搜索飞书文档。
- 用户提供本地文件时，将其作为补充来源；涉及本地 Office/WPS 文件时，调用对应的文档处理能力。
- 只做读取、搜索、分析和草稿生成时可直接执行。

### 3. 核对事实与来源

为每个关键事实保留以下信息中的至少一项：

- 文档标题与链接
- 文档日期或会议日期
- 章节、表格、段落或页码
- 发言人或记录责任人（原文明确时）

将内容区分为：

- **明确事实**：原始资料直接记录。
- **合理归纳**：由多条事实概括得出，注明“归纳”。
- **推测或建议**：不是原始事实，明确标注。
- **信息缺失**：原始资料没有提供。

### 4. 按任务类型处理

#### 文档整理与总结

提取并重组：

1. 一句话结论
2. 背景与目标
3. 关键事实或数据
4. 已确定事项
5. 未决问题与风险
6. 建议动作
7. 来源清单

#### 会议纪要与待办

提取并区分：

1. 会议主题、时间、参与人（资料明确时）
2. 核心讨论点
3. 已达成决策
4. 行动项：事项、负责人、截止时间、状态、依赖
5. 未决问题
6. 风险与分歧
7. 来源链接

不得把讨论建议自动升级为会议决策，不得猜测负责人和截止时间。

#### 周报与进展汇总

按时间范围汇总：

1. 本周期目标
2. 已完成事项与结果
3. 进行中事项与当前状态
4. 关键决策和协作进展
5. 问题、风险和阻塞
6. 下周期计划
7. 需要支持或确认的事项
8. 来源清单

合并重复记录，保留重要变化；同一事项存在多个版本时优先展示最新记录，同时说明变化来源。

#### 资料归类与检索

按“主题—时间—项目—资料类型—状态”建立轻量索引。每条索引至少包含：标题、简述、日期、来源链接、适用场景。只生成索引或整理建议，不移动、改名或删除原始资料，除非用户明确确认。

### 5. 生成双层交付

默认同时提供：

1. **聊天内结构化摘要**：便于快速阅读和决策。
2. **正式文档草稿**：适合保存、分享或后续编辑。

正式文档只有在用户明确需要文件、云文档或可分享成果时生成。选择格式时：

- 协作和持续更新：优先飞书文档草稿，但创建或修改前先确认。
- 本地交付：根据用途选择 Markdown、Word、Excel、PDF 或演示文稿。
- 不确定格式：先输出聊天摘要，再询问是否需要生成正式文件。

读取 `references/output-templates.md` 选择对应结构；需要本地正式文档时，可参考 `assets/daily-work-report-template.md`。

### 6. 外部操作确认

遇到以下动作时先停止并请求确认：

- 修改、创建或覆盖飞书文档
- 发送飞书消息、邮件或其他对外内容
- 创建或修改任务、日程、审批
- 上传、移动、重命名或删除共享资产

确认前展示：目标位置、拟写入内容摘要、影响范围和可逆性。取得明确确认后再执行。

## 默认聊天输出

使用以下顺序，按资料情况省略空项：

1. **结论**
2. **关键依据**
3. **行动项**
4. **风险 / 待确认**
5. **来源**
6. **正式文档**（如已生成，提供文件或链接）

## 质量检查

交付前检查：

- 是否回答了用户的实际问题，而非只复述资料。
- 是否清楚区分事实、归纳、建议和推测。
- 是否遗漏负责人、截止时间、状态或依赖。
- 是否保留足够的来源信息。
- 是否暴露资料冲突和缺失信息。
- 是否在任何外部写操作前取得确认。
- 是否避免冗长重复，并把最重要结论放在最前面。
