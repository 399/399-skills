## Properties 规则

默认允许：

```yaml
状态: 待验证
原内容标题: 原标题
来源:
  - URL
```

- 新整理食谱的状态默认为“待验证”。
- 原标题或链接不存在时省略相应属性。
- 不添加 `类型`；由文件夹区分菜谱、复做记录、食材和技法。
- 不添加份量、耗时、主动操作、主食材、烹饪方式或设备属性。
- 新属性必须有明确的跨食谱筛选、排序或汇总需求，不能仅因信息“有用”而增加。

## 整理提示

仅在存在以下问题时生成：

- 关键主料或核心配比未说明；
- 同一用量、时间、温度或步骤前后冲突；
- 总量存在，但关键阶段的分配方式不明；
- 烘烤、油炸、发酵等关键条件缺失，导致难以执行；
- 步骤使用了需要非显然前置处理的状态，但来源没有处理方法；
- 外部总结提供了无法确认的换算，并且可能影响复现。

不要提示：

- 内容来自外部总结；
- 盐、油、葱花等写作“适量、少许”；
- 普通炒菜步骤没有逐步说明火候；
- 不影响操作的背景信息缺失；
- 可选装饰没有用量。

## 设备

使用：

```markdown
> [!info] 所需设备
> 破壁机、电饭锅
```

记录满足以下条件的设备：

- 缺少它就无法按原方法完成；
- 替换它会明显改变流程或结果；
- 规格本身影响成品，例如特定尺寸模具；
- 温度计、电子秤等在当前食谱中承担关键控制作用。

通常不记录：

- 刀、砧板、碗、盘；
- 筷子、勺子、锅铲；
- 普通容器和可随手替代的小工具。

设备只在 Callout 中出现，不写入 Properties。

## 食材表

### 总量原则

主配方用一张表展示开始制作前需要备齐的全部食材及全篇总量。

```markdown
| 食材 | 用量 | 备注 |
|---|---:|---|
| 盐 | 5 g | 分次使用 |
```

若来源给出阶段分配，在步骤中写：

```markdown
1. 取2 g盐腌制鸡肉。
2. 炒制时加入剩余3 g盐。
```

若来源只给5 g总量，未给分配方法：

- 食材表写 `5 g`；
- 备注写 `分次使用`；
- 不自行拆成2 g和3 g；
- 分配方式会明显影响结果时，加入整理提示。

若同一食材在一个阶段有明确量、另一阶段用量未说明：

```markdown
| 食材 | 用量 | 备注 |
|---|---:|---|
| 生抽 | 至少2勺 | 腌制用量未说明；分次使用 |
```

不要在用量列写成 `2勺 + 未说明`。用量列保持可读，未知部分放入备注。

### 用量词

- 原文为明确量：`15 g`
- 原文为范围：`10–20 g`
- 原文为模糊调节量：`适量`、`少许`
- 原文没有用量：`未说明`
- 原文为容器量：`1勺`、`1饭碗`

不得把“未说明”改成“适量”，也不得自行把“1勺”换算成克或毫升。

### 备注准入

允许：

- `可选`
- `分次使用`
- `总结估算约200 g`
- `可用白粽子替代`
- `原文仅说明熟重`

禁止：

- `用于制作盐水冰`
- `增加奶香`
- `提供软糯口感`
- `切块`
- `完全冷却`
- 后续步骤已经明确表达的用途或操作

## 准备

准备包括：

- 清洗和切配；
- 腌制、泡发、浸泡和解冻；
- 调制酱汁；
- 提前冷冻或冷却；
- 预热设备；
- 开火后无法从容处理、实际需要提前完成的基础动作。

制作步骤出现“蒜末”但此前只有“大蒜”时，补入“大蒜切末”。出现“泡发后的木耳”却没有泡发信息时，不编造泡发方法，加入整理提示。

在准备步骤中写明已知用量、比例、操作和状态。例如：

```markdown
1. 将600 ml水和2–3 g盐混合，冷冻至少4小时，至完全冻硬。
```

比例只影响某个准备动作时，写在该步骤，不重复放入食材表。

## 制作

优先写成：

> 对象和用量 + 操作方式 + 火候、温度或时间 + 完成状态

示例：

```markdown
1. 将200 g鸡腿肉放入锅中，中火翻炒约3分钟，至表面完全变色。
```

不完整来源：

```text
放入鸡肉炒熟。
```

规范输出：

```markdown
1. 放入鸡肉炒熟。
```

不要补写来源没有提供的重量、火候、时间或颜色标准。

完成状态和提醒就地合并：

```markdown
2. 将熟糯米摊开并完全冷却。不要使用温热的糯米，否则会使冰浆迅速融化。
```

不要另设“成功标准”或“关键提醒”。

## 可选变化

只有来源给出实际食材或步骤变化时才生成。

- 单纯更换口味：使用项目列表或简短说明。
- 配方总量不同：另建食材表，并注明它不与主配方总量合并。
- 主要流程完全不同：优先拆成独立食谱。
- 不保留成本、节时比例或“更正宗”等宣传比较。

```markdown
# 贵州冰浆（正统版）

> [!warning] 整理提示
> - 原教程没有说明成品份量。
> - 盐水冰一次制作600 ml，但每次使用量为“1饭碗”，未说明具体重量及一批可制作多少份。
> - 原教程没有说明生糯米用量，只说明制作时加入约60 g熟糯米。

> [!info] 所需设备
> 冷冻设备、电饭锅、破壁机

## 食材

| 食材 | 用量 | 备注 |
|---|---:|---|
| 矿泉水 | 600 ml | |
| 盐 | 2–3 g | |
| 糯米 | 未说明 | 原文仅说明熟重 |
| 水果 | 1饭碗 | 总结估算约200 g |
| 奶粉 | 1–2勺 | |
| 凉白开 | 1勺 | |
| 糖浆 | 15 g | 可选；根据水果甜度调整 |

## 准备

1. 将600 ml矿泉水与2–3 g盐混合均匀，装入制冰容器或保鲜袋，冷冻至少4小时。完全冻硬后敲碎备用。

2. 糯米无需浸泡，按照糯米与水 `3:2` 的比例放入电饭锅煮熟。取约60 g熟糯米，摊开并完全冷却。不要使用温热的糯米，否则会使冰浆迅速融化。

3. 将水果清洗并切块，准备1饭碗。

## 制作

1. 将1饭碗水果、1饭碗盐水冰、1勺凉白开和1–2勺奶粉放入破壁机。根据水果甜度决定是否加入15 g糖浆。

2. 搅打约10秒，至水果和盐水冰形成冰沙状。

3. 加入约60 g完全冷却的熟糯米，根据希望得到的口感继续搅打：

   - 保留糯米颗粒：搅打约3秒；
   - 口感更加顺滑：搅打10–15秒。

4. 搅打完成后立即食用，避免久置融化。

## 可选变化

水果可以更换为芒果、黄瓜与牛奶组合或西瓜。原教程没有提供各口味的独立配方，更换水果后所需糖浆和液体量需要通过复做确定。

### 懒人版

懒人版使用另一套配方，不与正统版的食材总量合并：

| 食材 | 用量 | 备注 |
|---|---:|---|
| 冷冻水果 | 200 g | |
| 成品白粽子 | 1个 | 代替现煮糯米 |
| 奶粉 | 15 g | |
| 糖浆 | 15 g | |
| 盐水冰 | 200 g | 可选；不加时成品可能更稀 |

将上述材料放入破壁机直接搅打。原总结没有提供搅打时间和明确的完成状态。
```
